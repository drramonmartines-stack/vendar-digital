# Venda Digital

Operação de venda de um produto digital (ticket R$37 a R$50) via Instagram: pesquisa de nicho, produto, funil, landing page, entrega automática, anúncios e métricas.

## Estrutura

- `simulador/`: simulador de compradores sintéticos (Monte Carlo + personas) para estimar vendas e ROI por nicho antes de investir em anúncios.
- `docs/`: relatórios de pesquisa e decisões.
